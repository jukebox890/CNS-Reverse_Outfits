# Outfit Colours 0.4.10

- New outfit recolour icon for the preparer and generated installer executables.
- The same embedded artwork appears in their window and taskbar icons.

Colour conversion, skin preservation, saved alternatives, CNS compatibility and
auxiliary component handling are unchanged from 0.4.9. Existing preparations and
installed colour variants remain usable. Future generated installer outputs use
the updated icon; existing exported installers keep their previous icon.
