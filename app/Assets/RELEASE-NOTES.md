# Outfit Colours 0.4.12

- Unreadable or unsupported headers in unrelated installed .utoc files now produce
  a warning instead of stopping outfit scans, packaging or installation.
- Filename chunk reservations are still checked for unreadable packages. Readable
  container IDs and every generated/incoming package remain strictly validated.
- Invalid CNS definition rows no longer hide valid outfits later in the same file.
- Retains the 0.4.11 process-only PowerShell launch fix.

Colour conversion, skin preservation and in-game helper behaviour are unchanged.
Existing preparations remain usable. Extract the full new download and run the
new EXE. Prepare again before installing so newly exported installers contain
this update. Unrelated installed mod files are never repaired, removed or changed.
